클라우드 동기화 설정 (Supabase)

설정하면 모든 직원이 하나의 대장을 공유하고, 배차 신청이 즉시 모두에게 반영되며 같은 차량·시간대 중복 신청이 즉시 차단됩니다. 무료 플랜으로 충분합니다.

최초 1회 설정 (약 5분)

1. supabase.com 무료 가입 → New project 생성 (이름 예: kum-dispatch)

2. 좌측 SQL Editor → New query → 아래 SQL 전체 복사·붙여넣기 → Run

3. 좌측 하단 Project Settings → API 에서 Project URL과 anon public key 복사

4. 아래 입력란에 붙여넣고 연결 및 동기화 시작

연결 정보는 이 브라우저에만 저장되며 외부로 전송되지 않습니다. anon key는 공개 키라 안전합니다(서비스 키 service_role은 절대 사용 금지).
